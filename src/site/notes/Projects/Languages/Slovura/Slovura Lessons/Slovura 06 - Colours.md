# [[Projects/Languages/Slovura/Slovura Lessons/Slovura 06 - Colours\|Slovura 06 - Colours]]

Slovura does not need a separate basic root for every colour. Instead, colours provide a practical example of the [[Projects/Languages/Slovura/Slovura Lessons/Slovura 04 - Compound Words\|compound-word system]].

Colour words are compounds headed by [[Projects/Languages/Slovura/Slovura Roots/ku\|ku]], meaning **colour**. The following root identifies something characteristically associated with that colour.

> [!note] Colour structure
> **ku + reference**
>
> colour + something characteristically having that colour

Because [[Projects/Languages/Slovura/Slovura Roots/ku\|ku]] is the first root, the resulting word fundamentally describes a **colour**. The following root tells you which colour by referring to a familiar object, substance or concept.

This illustrates an important principle of Slovura: a language does not always need a dedicated root for every commonly named category. More specific concepts can be constructed from reusable basic ideas.

## Colour Reference


```base
formulas:
  Word: link(file.name, file.name.replace(/slovura_word_/, ""))
properties:
  note.meaning:
    displayName: Meaning
  note.logic:
    displayName: Logic
views:
  - type: table
    name: Colours
    filters:
      and:
        - file.hasTag("slovura")
        - file.hasTag("colour")
    order:
      - formula.Word
      - meaning
      - logic

```


> [!tip]
> Treat these compounds as descriptions first. Their conventional English colour names are useful translations, but the internal Slovura meaning comes from the roots that form them.
