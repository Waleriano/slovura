# [[Projects/Languages/Slovura/Slovura Lessons/Slovura 01 - Slovura Roots\|Slovura 01 - Slovura Roots]]

[[Projects/Languages/Slovura/Slovura\|Slovura]] is built from **monosyllabic roots**. Each root represents a basic concept or a group of closely related concepts.

A root should not be thought of as an exact translation of a single English word. Depending on how it is used, the same root may function like an English noun, verb, adjective or another part of speech.

## Root Shape

Every basic Slovura root consists of **one syllable** in one of these forms:

- **CV** - a consonant followed by a vowel
- **CCV** - a consonant cluster followed by a vowel

Roots therefore end in vowels. This becomes especially useful when roots are joined together into [[Projects/Languages/Slovura/Slovura Lessons/Slovura 04 - Compound Words\|compound words]]: the boundaries remain pronounceable without introducing additional sounds.

## Learning the Roots

You do **not** need to memorize the complete root inventory before moving on to the next lesson.

Start by learning roots that occur in examples and use the list below as a reference. As you begin constructing sentences and compound words, the more common roots will become familiar naturally.

Some roots have etymologies intended as mnemonic aids. These explain where the sound of a root came from; they do not restrict the meaning of the root.

      - property: formula.prefix
