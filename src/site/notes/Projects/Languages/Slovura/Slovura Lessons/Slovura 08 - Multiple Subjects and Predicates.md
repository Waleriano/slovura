# [[Slovura 08 - Multiple Subjects, Predicates and Objects\|Slovura 08 - Multiple Subjects, Predicates and Objects]]

The basic sentence structure from [[Projects/Languages/Slovura/Slovura Lessons/Slovura 02 - Basic Sentence Structure\|Slovura 02 - Basic Sentence Structure]] can be extended when a sentence has more than one **subject**, **predicate**, or **object**.

[[Projects/Languages/Slovura/Slovura\|Slovura]] does this by repeating the particle that introduces the relevant part of the sentence.

## Multiple Subjects

A sentence can be about more than one subject. Multiple subjects are joined with the particle [[Projects/Languages/Slovura/Slovura Roots/i\|i]].

> [!note] Multiple subjects
> **subject** [[Projects/Languages/Slovura/Slovura Roots/i\|i]] **subject** [[Projects/Languages/Slovura/Slovura Roots/li\|li]] **predicate**

> [!example] Example
> **[[Projects/Languages/Slovura/Slovura Roots/mi\|mi]] [[Projects/Languages/Slovura/Slovura Roots/i\|i]] [[Projects/Languages/Slovura/Slovura Roots/le\|le]] [[Projects/Languages/Slovura/Slovura Roots/li\|li]] [[Projects/Languages/Slovura/Slovura Roots/me\|me]] [[Projects/Languages/Slovura/Slovura Roots/e\|e]] [[Projects/Languages/Slovura/Slovura Roots/flo\|flo]].**
>
> I · and · she · predicate marker · have · object marker · money
>
> **She and I have money.**

The subjects `mi` and `le` share the same predicate.

## Multiple Predicates

One subject can have more than one predicate. Introduce each predicate with another [[Projects/Languages/Slovura/Slovura Roots/li\|li]].

> [!note] Multiple predicates
> **subject** [[Projects/Languages/Slovura/Slovura Roots/li\|li]] **predicate** [[Projects/Languages/Slovura/Slovura Roots/li\|li]] **predicate**

> [!example] Example
> **[[Projects/Languages/Slovura/Slovura Roots/mi\|mi]] [[Projects/Languages/Slovura/Slovura Roots/li\|li]] [[Projects/Languages/Slovura/Slovura Roots/mo\|mo]] [[Projects/Languages/Slovura/Slovura Roots/e\|e]] [[Projects/Languages/Slovura/Slovura Roots/fru\|fru]] [[Projects/Languages/Slovura/Slovura Roots/li\|li]] [[Projects/Languages/Slovura/Slovura Roots/me\|me]] [[Projects/Languages/Slovura/Slovura Roots/e\|e]] [[Projects/Languages/Slovura/Slovura Roots/flo\|flo]].**
>
> I · predicate marker · eat · object marker · fruit · predicate marker · have · object marker · money
>
> **I eat fruit and have money.**

Both predicates describe the same subject, `mi`.

> `mi` **li** `mo e fru`
>
> `mi` **li** `me e flo`

Because the subject is shared, it only needs to be stated once. Each repeated `li` begins another predicate about that same subject.

## Multiple Objects

A single predicate can also apply to more than one direct object. Each object is introduced with its own [[Projects/Languages/Slovura/Slovura Roots/e\|e]].

> [!note] Multiple objects
> **subject** [[Projects/Languages/Slovura/Slovura Roots/li\|li]] **predicate** [[Projects/Languages/Slovura/Slovura Roots/e\|e]] **object** [[Projects/Languages/Slovura/Slovura Roots/e\|e]] **object**

> [!example] Example
> **[[Projects/Languages/Slovura/Slovura Roots/mi\|mi]] [[Projects/Languages/Slovura/Slovura Roots/li\|li]] [[Projects/Languages/Slovura/Slovura Roots/me\|me]] [[Projects/Languages/Slovura/Slovura Roots/e\|e]] [[Projects/Languages/Slovura/Slovura Roots/flo\|flo]] [[Projects/Languages/Slovura/Slovura Roots/e\|e]] [[Projects/Languages/Slovura/Slovura Roots/fru\|fru]].**
>
> I · predicate marker · have · object marker · money · object marker · fruit
>
> **I have money and fruit.**

Both `flo` and `fru` are objects of the same predicate, `me`.

Each repeated `e` adds another object to the current predicate.

## Remember

> [!summary]
> - Use [[Projects/Languages/Slovura/Slovura Roots/i\|i]] to join multiple **subjects**.
> - Repeat [[Projects/Languages/Slovura/Slovura Roots/li\|li]] to introduce multiple **predicates** for the same subject.
> - Repeat [[Projects/Languages/Slovura/Slovura Roots/e\|e]] to introduce multiple **objects** for the same predicate.

This keeps the relationships between the parts of a sentence explicit even as the sentence becomes more complex.
